# Mapping Los Angeles Neon 

A project to map and photograph authentic neon around the city of Los Angeles.

## Usage

### Run local development server:

```bash
cd neon-map
npm install
npm run start
```

### Deploy to gh-pages:

```bash
npm run build   # build using vite 
npm run deploy  # deploy build to gh-pages
```
